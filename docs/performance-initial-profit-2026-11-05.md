# 总览图表使用初始预估盈亏

总览绿色柱及图例改为读取 `profitBaselines` 中首次完整导入时保存的产品初始盈亏（保留原运营费用口径），不再使用随退款浮动的最新结果。日、月及多店汇总按店铺和日期去重；任一有数据的店铺日期未记录初始值时，该柱保持未知，不用最新值或零替代。零及负数正常展示。

悬浮提示并列显示初始预估盈亏、退款和最新盈亏。最新盈亏仍读取原已保存产品利润，不从初始值中再次扣除累计退款。顶部盈利、甲方及店铺汇总和盈利构成对话框保持原统计结果。

总览的启动数据不含新增扩展集合，因此页面通过现有只读行查询单独分页读取初始记录。查询绑定当前账号，读取前后核对版本，异常和超时显示读取失败并支持重试；不把失败当作没有记录。不读取账本，不写入 WorkbenchData、同步队列或数据库，不修改任何已有服务和同步文件。

305 项测试及 rows-v1 生产构建通过。新增测试覆盖固定初始值、变动最新值、历史缺失、零值与亏损、多店月汇总、只读查询分页、版本变化、跨账号隔离、异常和中止；原结算及同步测试全部通过。

已使用本地虚构样例核对柱状图、正常及缺失值提示、读取失败和重试恢复。不对生产数据进行导入、重算或修补。
