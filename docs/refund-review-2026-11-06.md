# 退款影响复盘

## 读取口径

- 只读取当前账户已保存的 `collectionRecords`；按店铺和原订单成交日期分组。
- 已发货退款优先使用已保存的 `orderShippedRefund`。旧记录若只有退款完成日期金额，不推算为成交日退款。
- 退款率 = 同成交日已发货退款 / 订单成交额。
- 订单入账率 = 已入账订单数 / 应入账订单数。分母为零时显示未知。
- 净回款比例 = 订单净回款 / 有效订单销售额。此值会受其他资金扣款影响，不代表退款单独造成的损失。
- 最新盈亏和当前盈亏直接读取已保存的结算结果；缺少成本时显示未知。

## 异常规则

每个完整自然周与同店此前连续 28 天比较。五周都必须逐日有已保存记录，且退款率分母有效。当前周退款率同时上升至少 2 个百分点、相对基准至少 50%，标为“退款升高”；历史退款率为零时只用绝对升幅条件。订单入账率或净回款比例同期下降至少 5 个百分点，标为“重点关注”。阈值用于筛查，不能证明退款造成回款下降。

默认范围截至最新已保存结算日期。没有已保存日期的区间不会补零，旧口径、缺失日期和不足五周的店铺会提示数据待核对。不同长度的退款金额以“当前周”对“前 28 天周均”展示。

## 自动文字复盘

页面根据当前筛选范围内已保存的结算汇总自动生成退款文字复盘，无需点击按钮、API 调用或付费。文字列出退款率异常的店铺与自然周、本期和前 28 天的退款金额及退款率、订单入账率、净回款比例、未回款和已保存盈亏，并提示缺失日期与旧退款口径。文字只解释已有统计结果，不推断退款与回款、利润变化的因果关系。
