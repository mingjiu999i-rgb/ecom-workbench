# 结算导出提醒提供可定位的对账明细

原导出校验将产品明细缺失、销售额差异、成本差异或推广费差异统一称为“产品利润数据尚未同步”，但它并非云端保存状态，且不列出日期与差额，容易导致用户反复核对或重导正确的原始报表。

本次保留原校验条件、金额容差、阻止导出规则及继续导出逻辑，只替换提醒的展示。弹窗按店铺、日期列出有效销售额、成本和推广费的两处已保存金额及差额，明确缺少明细时金额未知。保留原退款口径提醒并细化到日期。

从已保存索引中读取未归属产品或原产品已不存在的订单。补差价原金额恰好等于销售额缺口时，直接显示这一证据；其他情况只列为待核对线索，不断言原因。支持展开查看订单号、已保存商品 ID、原订单金额，并进入该日期已保存结果或基础资料中的商品链接核对。

不回填、不自动选择产品，不修改订单归属、销售额、成本、推广费或利润。订单原金额未扣后续退款，不能直接用于补写利润。数据在弹窗打开后发生更新时，按当前页面数据重新核对；差异已消除时明确提示重新导出。

生产只读核对确认：用户所示多个日期的销售额差异与未归属产品的补差价订单原金额相同；另有仅保存推广费而没有产品明细的日期。没有对生产数据进行修补或导入。

原 `settlementWorkbook.ts`、账本、计算、退款回填、成本匹配及所有保存/同步服务保持相同源文件指纹；`PddAnalyzer.tsx` 只接入提醒组件并调整说明文字，原导入、计算及导出处理函数由哈希测试确认未变。
