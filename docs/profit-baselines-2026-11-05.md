# 初始预估盈亏与最新盈亏

经营结算页面及导出的总览、产品预览、店铺回款明细新增初始预估盈亏。原随退款更新的预估盈亏改名为最新盈亏，沿用原金额和计算规则；原“当前盈亏”继续表示实际回款口径。

从此功能启用后的新导入开始，某个店铺日期首次完整导入订单、退款、资金和推广费报表，成本已匹配、退款资金已齐全且计算结果已保存时，单独复制该日期和各产品的现有预估结果。此值之后固定，重复导入或只补导退款、资金均不会覆盖。若首次导入的是历史日期，记录的是该次导入时点，不能解释为历史成交当天的原始预估。

历史记录不会因打开页面或导出而生成初始值。没有初始记录时显示“未记录”；包含未记录日期的汇总同样显示“未记录”，不将其视为零。推广费未提供、成本缺失、计算未保存时不锁定初始值。初始值为零或负数均正常保存。

记录位于独立的 `profitBaselines` 扩展集合中，使用现有行存储及草稿机制，无数据库迁移。初始值不会写回账本、订单、回款或产品利润记录，也不会参与原结算计算。单店清空及撤销包含对应初始记录。

总览及产品预览保留原产品利润口径（含运营费）；店铺回款明细及每日经营主表保留原每日汇总口径。新增名称不改变费用范围；最新盈亏沿用原预估规则，并不代表已经扣除全部资金费用。
